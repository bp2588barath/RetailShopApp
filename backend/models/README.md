# 🛒 Retail Shop Management System (MERN Full Stack)

A professional full-stack MERN Retail Shop Application with Customer and Owner (Admin) modules.

---

## 🚀 Features

### 👤 Customer Module
- Customer Register & Login (JWT Authentication)
- View Products
- Add Products to Cart
- Update Quantity / Remove Items from Cart
- Checkout (Cash on Delivery)
- View Order History

### 🛠 Owner (Admin) Module
- Owner Login
- Add / Delete Products
- View All Customer Orders
- Update Order Status (Pending / Packed / Delivered / Cancelled)

---

## 🧰 Tech Stack
- **Frontend:** React.js, Tailwind CSS, Axios, React Router DOM
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Authentication:** JWT (JSON Web Token)
